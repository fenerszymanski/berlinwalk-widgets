# Berlin Pocket Kit source manifest

Checked on **2026-08-22** in the Europe/Berlin calendar.

## Method

- I checked each venue against the venue's own website or a venue-owned primary profile. The source URL in pocket-kit-data.json is the page to recheck before leaving.
- I used a Google Maps search URL separately for each venue so a visitor can search the name and address without the Pocket Kit claiming that a listing, opening time or menu detail is permanent.
- I checked the official BVG, S-Bahn Berlin and VBB map landing pages instead of carrying forward mirrored PDFs whose validity could not be proven from the current source.
- A source check confirms that a place or primary profile was present when checked. It does not assert opening hours, review scores, rankings, card acceptance, dietary certification or availability.
