# BerlinWalk public runtime

This deployment-only repository contains the public files used by BerlinWalk tools and widgets.

The live directory is available at [fenerszymanski.github.io/berlinwalk-widgets](https://fenerszymanski.github.io/berlinwalk-widgets/). Source code, working files, quality-assurance records, and operational notes are maintained privately.

Please report security concerns privately as described in [SECURITY.md](SECURITY.md).
