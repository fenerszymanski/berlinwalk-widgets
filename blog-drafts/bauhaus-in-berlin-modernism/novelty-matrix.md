## Chosen mechanic

`Berlin Bauhaus Lineage Map` is a map-led architectural reading surface. A visitor selects one of three real Berlin coordinates — archive, house or public hall — and the map, current building photograph and short interpretation move together. The output is a scale-specific lens, not a route, recommendation list or duration calculation.

Fingerprint fields: primary mechanic = place-linked lineage map; input model = direct selection of a built scale; state progression = map pin / building card / comparison strip; output model = selected place plus its connection to the wider modernist thread; visual grammar = real architecture photographs over a dark-green cartographic field with yellow map pins and cream fact panels.
