# BerlinTool novelty matrix

Run: `2026-08-15-1217-Europe-Berlin`

## Chosen mechanic

`Berlin Walking Kit` is a sequential packing-tray assembly. The visitor first chooses the kind of ground and pace they expect, then fills three different rail slots — shoe, layer and carry — before receiving a `wear / carry / leave` arrangement tied to real Berlin places. It is not a route map, one-answer quiz, picker, checklist or calculator.

Fingerprint fields: primary mechanic = sequential kit assembly; input model = stage-gated ground choice plus three item groups; state progression = ground → shoe → layer → carry → reveal; output model = contextual wear/carry/leave rail with place-specific advice; visual grammar = editorial wardrobe rail with a real Berlin photograph, cream paper, yellow stitch line and green labels.
