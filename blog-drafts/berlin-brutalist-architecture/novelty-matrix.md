## Proposed tool fingerprint

- **Primary mechanic:** sequence four visual-architecture clues into a guided evidence chain.
- **Input model:** one observed facade clue per step, with retry feedback.
- **State progression:** clue selection, immediate factual reveal, practical detour card, then a deliberate next-building action.
- **Output model:** a building-specific exterior/access move, not a scored recommendation or route.
- **Visual grammar:** real licensed building photographs, dark field-notebook panels, a segmented evidence-chain rail and small labelled material chips.

Nearest match is `berlin-pink-pipe-decoder` at 2/5. It shares clue-to-answer language but not the visual input, multi-stage chain, building output, photo-led grammar or usable detour decision. No same-day package uses this primary mechanic or visual grammar.
